Pages in batch

Scan the first page

Each scan is collected as a page instead of being uploaded immediately. In the end, they merge into one PDF.

  • ⠿ Drag — hold and drag a page to reorder.
  • ↻ Rotate — rotates the page by 90° for the final PDF.
  • ⟳ Rescan — the next scan replaces this specific page.
  • × Remove — removes this page from the batch.
  • 🔍 Tap — shows full-size view with navigation arrows.

If a feeder stack comes out upside down or reversed, Rotate all and Reverse order fix it in one tap.

Save as PDF merges everything and sends it to Paperless. Discard clears the batch.

Post-processing

Duplex scanning often feeds blank reverse sides. A page is recognized as blank when nearly empty; skipped pages are noted in the live log.

Straightens crooked pages. The page is re-rasterized, taking an extra moment, but noticeably improves Paperless OCR quality.

Profiles

One tap instead of four switches: A profile stores source, resolution, color, format and tags. It appears as a button above the scan orb on the dashboard.

Extras

Optional features remain off by default to keep the dashboard lean.

Push notifications to phone off

Notifies you when Paperless confirms a document — even if the app is closed. Requires ScanDeck to be accessible via HTTPS and added to the home screen on iOS.

Home Assistant via MQTT off

The easiest way: ScanDeck automatically discovers itself in Home Assistant as a device — with buttons for scan, cancel and batch, plus sensors for status, progress, queue and feeder. No manual edits in configuration.yaml needed.

Access protection

Disabled by default for local home networks. When enabled, requires a password to access the UI — useful for guest Wi-Fi or shared networks. The Home Assistant API remains accessible via API key.

Access protection is active.

Cleanup

Only files confirmed by Paperless are deleted. Documents still queued, rejected or flagged as duplicates are kept.
